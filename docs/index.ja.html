01 — 選定

カメラを選ぶのに
必要な数字を、すべて

チップセットで動く analytics が決まり、画角で現場をカバーできるかが決まり、価格で承認が下りるかが決まります。この 3 つが、いま読んでいるページ上に表示されます — 別タブも表計算も不要です。

FEATURE / 01

カタログ全体をツールバーに

どのタブからでも、341 モデル・432 の価格付き SKU をモデル名または Axis 型番で検索できます。各行にはチップセット、定価、そして拡張機能内のすべてのリストで先頭に固定するハートが並びます。モデル名・型番・カテゴリーはクリックでコピーできます。

FEATURE / 02

よく開くカテゴリーを 4 つ

Axis の製品カテゴリーはポップアップ内から選べます — クイックリンク行の末尾の + です。axis.com でタイルにハートを付ける従来の方法もそのまま使え、どちらも同じ 4 件のショートカットに書き込まれ、常に同期します。上限は axis.com と同じ 4 件で、ラベルが省略表示にならないようにしています。

FEATURE / 03

チップセットで絞り込み、価格や画角で並べ替え

analytics が必要とする ARTPEC／Ambarella 世代に絞り込み、価格または画角の広い順で並べ替えます。どの並び順でもお気に入りは先頭に固定され、絞り込みはカタログとマップの結果に同時に適用されます。

NEW IN v6.0

AXIS OS 13 に対応する？ ディープラーニングは動く？

これまではサポートページとデータシートを開かなければ分からなかった 2 つの問いが、バッジ列で答えられるようになりました。OS 13 は Axis 自身の Y2038 に関する案内をもとにモデルごとに判定します — ARTPEC-6 製品は対象外で、公開情報どうしが食い違う場合は推測せずバッジを出しません。DLPU / MLPU は Axis の製品セレクターのフィードから取得しています。チップセットの世代は手がかりになりません — ARTPEC-7 だけでもディープラーニング、機械学習、演算ユニットなしの 3 種類が混在しているからです。

FEATURE / 04

axis.com 上に直接バッジを表示

認識されたすべての製品カードに最大 4 つのバッジ — チップセット、AXIS OS 13、DLPU / MLPU、価格 — が付きます。製品セレクター、検索結果、製品・カテゴリーページ、そして製品比較表の中にも表示されます。4 つはそれぞれ設定画面で個別にオフにできます。

FEATURE / 05

製品セレクターにはなかった絞り込みパネル

チップセットの複数選択、必要画角のスライダー、CamStreamer 対応機種に絞り込む ACAP ドロップダウン、シリーズの安い順ソート — すべてページにその場で適用されます。上部には固定したカテゴリーとツールがワンクリックで並びます。

FEATURE / 06

クリックした項目を、そのままコピー

型番は見積書へ、モデル名はメールへ、カテゴリーは仕様書へ — 必要な項目をクリックするだけでクリップボードに入り、チェックマークで確認できます。複数個パックの SKU は (10 pcs) の接尾辞を除いてコピーされるため、貼り付けた番号がそのまま発注に使えます。

FEATURE / 07

あなたの言語で使えます

ポップアップ、パネル、スキャナーのすべての文言が12 言語に翻訳されています — 英語、チェコ語、日本語、スペイン語、ドイツ語、フランス語、韓国語、中国語、スウェーデン語、ウクライナ語、アラビア語、オランダ語。初回はブラウザーの設定から自動で選ばれ、国旗の列でいつでも切り替えられます。

FEATURE / 08

Mac と Linux にも、ついに IP Utility を

Axis が提供してきたのは Windows 版の AXIS IP Utility だけでした。Mac や Linux のインテグレーターは、Windows 機を借りるか、仮想マシンを立てるか、アドレスを当てずっぽうで試すしかありませんでした。

これは同じ作業をブラウザーで行うツールです。Chrome または Firefox が動く環境ならどこでも — macOS、Windows、Linux、ChromeOS で動作します。サブネットを入力して Scan を押せば、応答した機器が順に表示されます。モデル、IP、シリアル、ファームウェア、チップセットを VAPIX 経由でカメラから直接取得し、インストールも不要、データが端末の外に出ることもありません。

02 — 撮影範囲

範囲を描けば、
カメラが決まる。

カメラを設置する場所にピンを置き、映したい範囲まで扇形をドラッグすると、下のリストが実際にカバーできるモデルに変わります。並び順は「広い順」ではなく「無駄なく収まる順」です。

  • PTZ の旋回も、正直に評価。 旋回してはじめて必要な角度に届く PTZ は、扇形をそのままカバーできる機種より下に並びます。PTZ が一度に見られるのは 1 方向だけだからです。
  • 無駄のない順に。 360° のパノラマカメラは理屈のうえでは 90° の扇形をカバーしますが、それが正解であることは稀です。結果は過剰スペックの少ない順に並び、同順位は価格で決まります。
  • カメラのみ。 クリップ、ライセンス、レコーダー、インターコムには画角がないため表示されません。安い順に並べ替えてもリストはカメラのままです。
  • 条件はひとつ。 描いた扇形と「必要な FoV」スライダーは同じ値で、ポップアップ、マップ、製品セレクターのパネルで共有されます。
03 — ネットワーク

現場にすでにある
Axis 機器

IP Utility スキャナー

サブネットを入力して Scan を押すと、応答したすべての Axis 機器が — モデル、IP、シリアル、ファームウェア、チップセットとともに一覧表示され、引き渡し書類用に CSV で書き出せます。結果はスキャンの進行に合わせて順次表示されるため、254 アドレスすべてを待たずに最初のカメラを確認できます。

  • 各アドレスに VAPIX の basicdeviceinfo で公開デバイス情報を問い合わせます。AXIS OS 10 以降ではパスワード不要です。
  • 権限は入力したサブネットのみに対して、スキャンする時点で要求されます。インストール時には何も付与されません。
  • データは PC の外に出ません。 サーバーもテレメトリーもありません。結果はローカルストレージに保存され、ポップアップを開き直せば前回のスキャン結果がすぐ表示されます。
  • 192.168.0、192.168.1、10.0.0、および工場出荷時の .90 アドレスのプリセット付き。

ワンクリック、
デベロッパーモード不要

06 — 価格

あなたの価格表を、
そのまま

毎月の .xls をドロップするだけ

同梱のカタログは公開されている AXIS 価格表です。新しい価格表が届いたら、設定ページに .xls をドロップするだけで、すべてのバッジ・ポップアップの行・マップの結果があなたの数字に置き換わります — 再インストールも、リリース待ちも不要です。

  • 標準の AXIS 価格表は自動認識されます — All products シートを読み取り、全カテゴリーを網羅します。
  • それ以外の表計算ファイルも手動で列を対応付けできます。価格列の通貨も指定可能です。
  • 為替レートの取得以外、どこにもアップロードされません。同梱の価格に戻すでワンクリックで元に戻せます。
07 — データの出どころ

魔法もなければ、
あなたを追跡もしない

価格

catalog-data.js は公開されている AXIS 価格表から抽出した SKU ごとのデータを保持します。定価として定義されているのは EUR のみで、USD・GBP・JPY はそこから為替換算した概算です。概算であることが分かるよう先頭に ~ が付きます。

チップセット

chipset-data.js は CamStreamer の対応ハードウェア一覧から解析したスナップショットを同梱しています。バックグラウンドのサービスワーカーが毎週更新するほか、ポップアップから手動更新もできます。

画角

fov-data.js は各モデルの水平画角の最小値と最大値を保持します。PTZ の全旋回範囲をカバー範囲として扱うのは、それが妥当な場合のみです。画角データのないモデルは一致とみなされません。

ネットワーク

スキャン結果は VAPIX 経由でカメラから直接読み取り、ローカルストレージに保存されます。どこにも送信されません — この拡張機能にサーバーはなく、アカウントも解析もありません。
