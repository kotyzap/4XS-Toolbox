Prices are Axis MSRP (list price), not street price. EUR is from the AXIS Price List, July 2026 (camera products only - EUR isn't available for non-camera categories like 2N, recorders, or accessories). USD for those same products is calculated from the EUR price at the EUR/USD rate in effect when this list was last generated (1 EUR ≈ 1.1387 USD, per xe.com on 2026-07-14) - it is not an independently published Axis USD price list, so treat it as an estimate. JPY is converted live from the EUR price using the current EUR/JPY reference rate (ECB, via api.frankfurter.dev), refreshed on the same weekly schedule as chipset data. Chipset info is sourced from CamStreamer's published app-compatibility list, not Axis. None of this refreshes automatically except chipset data and FX rates via the weekly background check or the Update button above.
